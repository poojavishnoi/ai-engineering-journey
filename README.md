I'm a frontend & mobile engineer (React, React Native, TypeScript) learning to build **production AI features**, in public, over 12 weeks.

Rule for myself: **build it from scratch first, use the framework second.** If I can't explain it simply, I don't understand it yet.

## 🗺️ The plan

1. **Weeks 1–4: How LLMs actually work.** Tokens, embeddings, sampling, the raw API, tool calling, an agent loop from scratch, a streaming chat app with generative UI.
2. **Weeks 5–8: Retrieval & evals.** Embeddings, vector search, RAG done properly, measuring quality → a bug-triage copilot.
3. **Weeks 9–12: Agents in production.** MCP, guardrails, prompt injection, cost & latency, on-device and multimodal AI in React Native → capstone.
